# reports

This directory holds the **outcome** side of graph-memory experiments: what a
run (or a batch of runs) showed, after the raw logs have been reviewed.

What goes here:

* processed results and score summaries;
* comparisons between runs (e.g. different walker policies, different graph
  sizes);
* reviews and conclusions written after looking at the raw logs;
* anything meant to be read by someone who was not there when the run happened.

What does not go here: run configs, scripts, or in-progress setup notes — see
[`experiments/`](../experiments/README.md) for those.
