# Graph Memory Manual ChatGPT Extended

Расширенная версия учебного курса по архитектуре памяти RIN.

Что добавлено по сравнению с базовым учебным дублем:

- более явный пролог о жанре, маршрутах чтения и статусе расширений;
- отдельная математическая глава о retrieval как операторе на графе;
- отдельная глава о каналах свидетельств, калибровке уверенности и ревизии;
- сквозные worked examples от события до ответа и обратной ревизии;
- отдельный модуль о failure modes, диагностике и инженерных предохранителях;
- разбор архитектурных развилок и будущих исследовательских ветвей.

Сборка:

1. Двухпроходный `xelatex`.
2. PDF должен оказаться в `out/main.pdf`.

Важно:

- базовый roadmap сохранён;
- новые технические предложения в тексте отмечаются как расширения, а не выдаются за исходник;
- в этой версии убраны сравнения с посторонними проектами и прямое обращение к читателю во втором лице.
