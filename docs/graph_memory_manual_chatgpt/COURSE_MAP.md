# Карта курса

## Что это за версия

`graph_memory_manual_chatgpt_extended` — не замена базовому дублю, а следующий слой.
Если базовый текст стремился сделать roadmap читаемым как учебник, то расширенный
вариант стремится сделать его похожим уже на полноценный курс: с более явной
математикой, с систематической диагностикой, со сквозными примерами и с открытым
разделением на архитектурные решения, инженерные компромиссы и исследовательские
ветви.

## Маршруты чтения

1. Короткий маршрут:
   пролог -> введение -> архитектура -> определения -> Stage 1 -> эксперимент.

2. Архитектурный маршрут:
   архитектура -> субстрат -> walker -> topology -> fusion -> runtime -> failure modes.

3. Математический маршрут:
   определения -> walker -> retrieval math -> epistemics -> propagation ->
   evidence calculus -> experiment.

4. Исследовательский маршрут:
   topology -> learning -> dynamical memory -> future branches.

## Новые расширения относительно roadmap

- Явная retrieval-метрика как кортеж диагностик:
  `anchor recall`, `bridge rate`, `contradiction hit rate`, `provenance coverage`.

- Более формальная схема каналов свидетельств:
  наблюдение, внешний отчёт, вывод, само-модель, социальная индукция, с разной
  надёжностью и штрафом за зависимость источников.

- Разделение бюджетов контекст-пакера:
  бюджет на узлы-свидетельства и отдельный бюджет на связующий материал.

- Явная инженерная карта failure modes:
  от hub collapse и bottleneck starvation до erosion provenance и mood lock-in.
