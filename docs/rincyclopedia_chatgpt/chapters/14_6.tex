\section{Мини-библиография}

Теоретические работы, на которые эта книга прямо опирается:

\begin{itemize}
\item Масахиро Мори, эссе об uncanny valley, 1970 — теория провала доверия при неполном сходстве (0.1).
\item Скотт МакКлауд, "Understanding Comics", 1993 — amplification through simplification, теория иконического упрощения (0.3, 1.2).
\item Хироки Адзума, "Otaku: Japan's Database Animals", 2001 — database animals, теория элементного считывания персонажа (0.5, 1.5).
\end{itemize}

Смежные работы по аниме- и отаку-исследованиям, полезные для дальнейшего чтения за пределами этой книги (не цитировались напрямую, приводятся как контекст): Сьюзан Нейпир, "Anime from Akira to Howl's Moving Castle" — общий обзор аниме как культурного феномена; Патрик Гэлбрейт, работы о moe-культуре — более подробное развитие темы, затронутой в 1.5.
