\section{Few-shot exemplars: маленькая библиотека "идеальных реплик"}

Маленькая библиотека "идеальных реплик" — курируемый набор примеров, взятых из уже написанных сцен (в первую очередь 12.6--12.12), которые можно использовать как few-shot referenced material при генерации новых сцен или при калибровке модели.

Критерий отбора в эту библиотеку не "красиво звучит", а тройной тест, применённый по всей книге: проходит ли реплика проверку 2.1 (не рассыпается при извлечении из контекста), 2.2 (имеет отслеживаемую причину, а не жанровое умолчание) и 7.8 (невозможна у другого персонажа в том же режиме). Реплики, которые проходят все три теста, — надёжный материал для few-shot; реплики, которые технически работают, но держатся только на контексте конкретной сцены, в библиотеку не попадают.
