# Reports 2-9 LaTeX Project

Развернутый LaTeX-проект по серии экспериментов `exp2`-`exp9a`.

Важно:

- проект создан в доступной рабочей папке Codex, а не прямо в репозитории `RIN`,
  потому что в текущей сессии запись в `C:\Users\yaros\BlackSabbitch_repo\RIN`
  недоступна;
- структура папки специально сделана репозиторно-нейтральной, чтобы ее можно было
  перенести в репозиторий одной директорией;
- в тексте отдельно отмечено, что `8b` на момент свода является проектной веткой,
  а не исполненным ноутбуком.

Сборка:

1. Открыть папку проекта.
2. Запустить `xelatex main.tex`.
3. Повторить `xelatex main.tex` второй раз для корректного оглавления.

Ожидаемый артефакт:

- `main.pdf` в корне проекта или рядом с ним, в зависимости от локальной сборки.
