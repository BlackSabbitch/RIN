# Конструирование графовой памяти Рин — монография

LaTeX-проект (по образцу `docs/rincyclopedia_*`). Конспект проектных обсуждений
архитектуры памяти Рин, приведённый к форме монографии.

## Сборка

```bash
cd docs/graph_memory_manual
bash build.sh          # xelatex, PDF -> out/main.pdf
```

Нужны `texlive-xetex` и `texlive-lang-cyrillic`, а также шрифты Linux Libertine
(как в проектах Ринциклопедий).

## Структура

- `main.tex` — преамбула и порядок глав.
- `chapters/00..13_*.tex` — главы.
- `chapters/13_references.tex` — блок литературы (часть работ — из библиографий
  волтов RIN и RIN–DTI, это отмечено в тексте).

## О чём

Единый тезис: **память — это один типизированный темпоральный граф с
метаданными, а всё остальное (retrieval, пропагация уверенности, забывание,
ночные обходы, настроение, личность) — операторы над ним.** Монография
разворачивает субстрат, его динамику, эпистемическую гигиену, влияние
топологии, слой личности и голоса, а также программу экспериментов на
эрзац-графе. Стиль — академический, но с опорой на примеры и аналогии.
